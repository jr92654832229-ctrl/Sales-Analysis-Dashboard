# Sales Analysis Dashboard

## Project Overview
This project analyzes sales data using Python and Plotly. It provides insights into sales trends, product performance, city-wise sales, and key business metrics.

## Tools & Technologies
- Python
- Pandas
- Plotly
- Google Colab

## Features
- Data Cleaning
- Feature Engineering
- KPI Analysis
- Monthly Sales Analysis
- Product-wise Sales
- City-wise Sales
- Interactive Visualizations
- Business Insights

## Dataset
Sales Dataset (CSV)
